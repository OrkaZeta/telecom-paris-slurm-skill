# Télécom Paris Slurm Skill

A Codex and Claude Code skill for selecting Slurm resources, submitting jobs, and monitoring workloads on Télécom Paris clusters.

## Install

```bash
git clone https://github.com/OrkaZeta/telecom-paris-slurm-skill.git ~/.agents/skills/telecom-paris-slurm
```

For Claude Code, use `~/.claude/skills/telecom-paris-slurm` instead, or symlink that path to the installed directory.
